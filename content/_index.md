# 1242.2 Langage CPP

Ce cours est une introduction au langage C++ et à la programmation orientée objet (POO).
Il est destiné aux étudiants de la filière Ingénierie des Systèmes de Communication (ISC) de la HE-Arc Ingénierie.

Nous utiliserons le standard C++23.
Dans la grande majorité des cas, les concepts vus dans ce cours sont aussi valables pour les versions antérieures du langage (C++11, C++14, C++17, C++20).
Lorsque ce n'est pas le cas, ce sera clairement indiqué.
